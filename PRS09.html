Laboratoria 9 - Uczenie maszynowe na strumieniach danych: biblioteka River

Na wykładzie poznaliśmy uczenie online: model dostaje przykłady po jednym, najpierw przewiduje, potem poznaje prawdziwą odpowiedź i poprawia się odrobinę. Nie przechowuje danych, tylko swój stan. Na tych zajęciach zbudujemy takie modele w bibliotece River, ocenimy je ewaluacją progresywną, zobaczymy dryf pojęć i wykrywanie anomalii, a na końcu połączymy River z potokiem Streamz z poprzednich zajęć.

Przypomnienie: API River

Przykład to para (x, y): x to słownik cecha → wartość, y to odpowiedź. Wszystkie modele mają te same metody:

metodado czego
model.learn_one(x, y)uczy model jednym przykładem (nic nie zwraca)
model.predict_one(x)predykcja dla jednego przykładu
model.predict_proba_one(x)słownik {klasa: prawdopodobieństwo}
model.learn_one(x), model.score_one(x)modele bez etykiet: uczenie i wynik anomalii
metric.update(y, y_pred)aktualizacja metryki o jeden przykład

Podstawowa pętla test-then-train, którą będziemy powtarzać w każdym zadaniu:

for x, y in strumien:
    y_pred = model.predict_one(x)   # 1. przewiduj (model jeszcze nie zna y)
    metric.update(y, y_pred)        # 2. oceń
    model.learn_one(x, y)           # 3. ucz się

Zadanie 6. Anomalie w danych z czujnika

Poniższy generator symuluje czujnik temperatury i wilgotności w szklarni. Temperatura wolno zmienia się w ciągu doby, a ok. 1% pomiarów to awarie (nagły skok o 4–8 °C). Generator zwraca też informację, czy pomiar jest anomalią, żeby można było ocenić detektor.

import math
import random

def czujnik(n=3000, seed=7):
    """Strumień par (x, czy_anomalia) z czujnika w szklarni."""
    rng = random.Random(seed)
    for i in range(n):
        temp = 22 + 3 * math.sin(i / 200) + rng.gauss(0, 0.4)   # wolne zmiany w ciągu doby
        wilg = 60 + rng.gauss(0, 1.5)
        anomalia = rng.random() < 0.01                           # ok. 1% awarii
        if anomalia:
            temp += rng.choice([-1, 1]) * rng.uniform(4, 8)
        yield {'temp': temp, 'wilg': wilg}, anomalia
